## 📌 Sobre o Repositório

Este repositório foi criado para organizar meus estudos, anotações e códigos práticos para a certificação **Oracle Certified Professional: Java SE 21 Developer (Exam 1Z0-830)**.

O objetivo principal é documentar:
* 💡 **Conceitos teóricos e fundamentais** do livro oficial de estudos (*OCP Java SE 21 Developer Study Guide* por Jeanne Boyarsky e Scott Selikoff).
* 🎯 **Questões e simulados da Enthuware**, com foco na análise de erros, exceções de código e pegadinhas do compilador/JVM.
* 💻 **Exemplos práticos de código** cobrindo as novidades e recursos consolidados do Java 21.

---

## 📚 Tópicos Principais de Estudo

- [ ] **Fundamentos do Java & Tipos de Dados:** Primitivos, wrapper classes, escopo, var, immutability, Strings, StringBuilder e arrays.
- [ ] **Instruções de Controle de Fluxo & Estruturas:** `if/else`, `switch` clássico e *switch expressions*, loops (`for`, `while`, `do-while`).
- [ ] **Orientação a Objetos Avançada:** Herança, polimorfismo, classes abstratas, interfaces, enums, records e *sealed classes/interfaces*.
- [ ] **Programação Funcional:** Interfaces funcionais (`Predicate`, `Consumer`, `Function`, `Supplier`), expressões Lambda e Stream API.
- [ ] **Tratamento de Exceções & Assertions:** `try-catch-finally`, `try-with-resources`, exceções checadas e não-checadas.
- [ ] **Concorrência & Threads:** Virtual Threads (Java 21), `ExecutorService`, sincronização, paralelismo e completable futures.
- [ ] **Coleções & Generics:** Listas, conjuntos, mapas, ordenação (`Comparable` e `Comparator`), wildcard.
- [ ] **Módulos & I/O:** Java Platform Module System (JPMS), NIO.2, serialização e manuseio de arquivos.
